# あすたの LP

公開用静的ファイルはルート、React・Vite・TypeScriptソースは source/ です。

## 更新

source/ で npm ci、npm run build:publication を実行し、source/dist/ の内容を公開ルートへ反映します。古いハッシュ付きJS/CSSは入れ替えます。GitHub Pages は main / (root) を使用します。

全HTMLは noindex,nofollow を指定しています。検索非掲載やアクセス制限を保証する設定ではありません。

公開LPの動作確認と有料契約受付の確認は別です。法的適合性を承認済みとはしていません。npm run check:release は有料契約受付に関する未確認事項がある間は通過しません。LPの閲覧やLINE追加では有料契約は成立しません。

顧客記録・契約書・非公開の事業者住所や電話番号・認証情報は保存しません。画像の権利は権利者に帰属し、無断再利用はできません。
